# Русификация интерфейса Bruce (M5StickC Plus2)

## Как это устроено

* **Шрифт.** Встроенный шрифт TFT_eSPI (GLCD 5×8, `lib/TFT_eSPI/Fonts/glcdfont.c`) получил
  64 глифа кириллицы. Они занимают коды `0x80..0xBF`: `А..Я` → `0x80..0x9F`, `а..я` → `0xA0..0xBF`,
  `Ё/ё` сводятся к `Е/е`. Глифы нарисованы в `cyrillic_glyphs.txt` и вписываются в шрифт командой
  `python tools/i18n/font_tool.py patch`.
  `drawChar()` дополнительно понимает настоящую UTF-8 кириллицу (U+0410..U+044F), поэтому имена
  файлов и SSID на русском тоже видны.
* **Однобайтовая кодировка.** Русский текст в прошивке хранится по одному байту на букву, поэтому
  `String::length()`, `substring()` и все расчёты вида «символы × 6 × размер» в Bruce работают
  без изменений: центрирование, перенос строк, обрезка и прокрутка.
* **Перевод на лету** (`src/core/i18n.cpp`). Английские строки в коде не трогаются. Перевод
  делается в момент вывода:
  * `tft_logger::drawString/drawCentreString/drawRightString/print/printf`, то есть всё, что
    рисуется на экране;
  * `display.cpp`: меню (`drawOptions`, `drawSubmenu`, прокрутка), заголовки, сообщения
    (`displayError/Info/...`), `padprintln/padprintf`; там текст переводится *до* расчёта
    ширины;
  * главное меню (карусель и сетка).

  Поиск идёт бинарным поиском по таблицам во flash. Поддерживаются точные строки, вариант
  ЗАГЛАВНЫМИ, префиксы (`"Connecting to " + ssid`), суффиксы (`n + " networks"`),
  метки с двоеточием (`"Status:" + value`) и форматы `printf` (`"Signal: %d dBm"`).
* **Метки пунктов меню (`Option::label`) остаются английскими внутри прошивки.** Это важно:
  по ним работают JS-скрипты, serial-команды, WebUI и сохранение файлов (например, имена кнопок
  ИК-пульта). Переводится только то, что видит пользователь.
* **Язык** переключается в *Настройки → Экран и интерфейс → Язык* (значение сохраняется в
  `/bruce.conf` как `"language": 0|1`). По умолчанию включён русский.
* **WebUI** (`embedded_resources/web_interface/index.js`) декодирует эту кодировку, поэтому
  зеркало экрана в браузере тоже показывает кириллицу.

## Словарь

* `ru.tsv` и `ru.d/*.tsv`: `тип<TAB>английский<TAB>русский`. Тип `=` означает точную строку,
  `^` префикс, `$` суффикс. Файлы читаются по алфавиту, поэтому более поздние переопределяют
  ранние (в `900_short_menu.tsv` лежат короткие формулировки для пунктов меню).
* `gen_i18n.py` собирает `src/core/i18n_ru_data.h`. Он вызывается автоматически при каждой
  сборке (`pre:tools/i18n/pio_gen_i18n.py` в `platformio.ini`) и прерывает сборку, если в переводе
  есть неподдерживаемый символ или в форматной строке не совпадают `%d/%s/...`.
* `extract.py ui candidates.tsv` выгружает все строки интерфейса из исходников (например,
  после обновления Bruce). Так видно, что ещё не переведено.
* `check_lengths.py` показывает переводы, которые не влезают в строку меню (19 символов).

## Проверка

* `python -m ziglang c++ -std=c++17 -I tools/i18n/test -I src/core tools/i18n/test/test_i18n.cpp -o t.exe && t.exe`
  запускает модульные тесты поиска перевода на компьютере.
* `render_preview.py out.png` рисует экраны 240×135 этим шрифтом и по разметке Bruce.
* `device_check.py COM5 status screen next screen` проверяет на устройстве через USB:
  serial-команда `i18n screen` возвращает последние нарисованные строки, а `i18n lang ru|en`
  переключает язык.

## Сборка и прошивка

```powershell
python -m platformio run -e m5stack-cplus2
python -m esptool --chip esp32 --port COM5 --baud 921600 write-flash -z 0x0 Bruce-m5stack-cplus2.bin
```

`Bruce-m5stack-cplus2.bin` — это полный образ (загрузчик, таблица разделов и приложение) для
адреса `0x0`. Раздел LittleFS с настройками он не затрагивает.

## Попутно исправлено в исходном Bruce

* `USBSerial::vprintf` передавал `va_list` в вариадический `printf`: вместо чисел выводились
  адреса, а `%s` вызывал падение (LoadProhibited).
* `display dump` держал на стеке задачи буфер 8 КБ и падал от переполнения стека.
