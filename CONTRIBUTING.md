# Как помочь Bruce RU

## Исправить или добавить перевод

Словарь — обычные TSV-файлы в [`tools/i18n/ru.d/`](tools/i18n/ru.d). Каждая строка: тип, оригинал и перевод, разделённые табуляцией.

```
=	Scan networks	Сканировать сети
```

- `=` — точное совпадение строки (пробелы по краям не важны);
- остальные типы (начало и конец строки, строки с `%d`/`%s`) описаны в [tools/i18n/README.md](tools/i18n/README.md).

Перевод должен влезать в экран 240×135: в строку меню помещается около 19 символов. Проверка длины — `python tools/i18n/check_lengths.py`.

Узнать, какие строки сейчас на экране стика: подключись к serial-порту (115200) и введи `i18n screen`.

## Добавить другой язык на кириллице

Шрифт уже содержит русский алфавит (`0x80..0xBF`). Для украинского, белорусского, казахского и т. п. нужно:

1. добавить недостающие буквы (`і ї є ґ ў қ ң …`) в [`tools/i18n/cyrillic_glyphs.txt`](tools/i18n/cyrillic_glyphs.txt) и свободные коды шрифта;
2. завести свой каталог словаря и значение в переключателе языка (`src/core/config.*`).

Открой issue перед началом — подскажу, как лучше устроить.

## Код

- Сборка: `pio run -e m5stack-cplus2`.
- Тесты перевода: `g++ -std=c++17 -I tools/i18n/test -I src/core tools/i18n/test/test_i18n.cpp -o t && ./t`.
- Интерфейс «Фосфор» — `src/core/ui_fosfor.*`, макеты — `tools/ui/fosfor_preview.py`.
- Ошибки, которые воспроизводятся и в английском Bruce, лучше отправлять также в [BruceDevices/firmware](https://github.com/BruceDevices/firmware).
